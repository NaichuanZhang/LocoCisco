      How it works

      1. SensorsUSB mic and camera. VAD, speech-to-text, voice labels and who-is-talking run on this box. Audio is dropped once it is text.
      2. Strands DeciderAnswers a typed question in about 100 ms: task, decision, question, room, nothing? With a probability for every option.
      3. Local LLM, only when unsureBelow the act threshold the local Qwen reads the transcript and the docs folder, with tools. Tokens never leave the box.
      4. PolicyPlain code. Guests hide the docs. “Off the record” always wins. The owner approves the recap.
      5. Devices and DiscordLamp and fan on the LAN. Tasks, decisions and the recap go to Discord as text through OpenClaw.

      Nothing but text leaves the box. The meter in the footer counts every byte.

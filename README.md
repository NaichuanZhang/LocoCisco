# LocoCisco presentation · GitHub Pages

**[Open the live slides](https://naichuanzhang.github.io/LocoCisco/)**

This branch publishes the five-slide HTML presentation at the site root.
GitHub Pages is configured to deploy from `lococisco`, `/ (root)`.

Source: [`Presentation/` at `af76e86`](https://github.com/NaichuanZhang/LocoCisco/blob/af76e86c0295d872fe766eec00476c33e2bf49fd/Presentation).
The application and editable presentation source remain on `main`.

This is a static release: CSS, JavaScript, fonts, illustrations, and the optional
source video are included. `.nojekyll` disables Jekyll processing. Evidence and
presenter-notes links point to the matching source revision on GitHub.

To update the site, copy `Presentation/index.html`, `presentation.css`,
`presentation.js`, `Demo.mp4`, `PRESENTER_NOTES.md`, and `assets/` from the desired
source revision to this branch root. Update the two document links in `index.html`
and this source reference, retain `.nojekyll`, and push `lococisco`.

Arrow keys or Space reveal builds. Keys 1–5 select slides; N opens notes and F
opens fullscreen. The opening slide accepts a local recording without uploading
it. The optional bundled `Demo.mp4` is source footage, not model-generated output.
